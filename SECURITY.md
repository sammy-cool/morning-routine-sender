## Reporting a Vulnerability

We take the security of **Morning Routine Sender** seriously.

If you believe you have found a security vulnerability in this repository, please **do not open a public GitHub issue**.

Instead, please report security vulnerabilities directly to the maintainers via:

- **Email:** `security@morning-routine-sender.com` (or the repository administrator)

### What to include in your report:

1. Type of issue (e.g. CSRF, XSS, Authentication bypass, HMAC validation gap).
2. Step-by-step instructions or proof-of-concept to reproduce the vulnerability.
3. Affected versions, endpoints, or components.

We will acknowledge receipt of your report within 48 hours and work with you to patch the vulnerability responsibly before public disclosure.
